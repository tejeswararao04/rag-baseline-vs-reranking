Chunking (run once, reused): 1000 characters, 150 overlap, skip parts under 200 chars. Result: 362 chunks with id and page number. Sample p4_5 page 4.

```python
from pypdf import PdfReader
pdf_path = "/kaggle/input/datasets/pailatejeswararao/niti-ai-strategy/NITI_AI_Strategy.pdf"
reader = PdfReader(pdf_path)
pages = [(i, (p.extract_text() or "").strip()) for i, p in enumerate(reader.pages)]
pages = [(i, t) for i, t in pages if t]
chunks = []
for pi, txt in pages:
    s = 0
    while s < len(txt):
        part = txt[s:s+1000].strip()
        if len(part) > 200:
            chunks.append({"id": f"p{pi:03d}_{len(chunks):04d}", "page": pi, "text": part})
        s += 1000 - 150
```

2. Two-Stage Retrieval Implementation
Pipeline 1 Baseline: (a) encode 362 chunks with Bi-Encoder, L2-normalize, add to FAISS IndexFlatIP for cosine via inner product (vectors shape 362x384, index total 362); (b) per query encode, normalize, search Top 10; (c) take Top 3 directly into fixed prompt for Answer 1.

```python
from sentence_transformers import SentenceTransformer
import faiss, numpy as np
model = SentenceTransformer("all-MiniLM-L6-v2")
vectors = model.encode([c["text"] for c in chunks], batch_size=32, convert_to_numpy=True)
norm = vectors / np.linalg.norm(vectors, axis=1, keepdims=True)
index = faiss.IndexFlatIP(norm.shape[1]); index.add(norm.astype("float32"))

def search_top10(query):
    q = model.encode([query], convert_to_numpy=True)
    q = q / np.linalg.norm(q, axis=1, keepdims=True)
    scores, ids = index.search(q.astype("float32"), 10)
    return [{"rank": r+1, "id": chunks[int(ids[0][r])]["id"], "page": chunks[int(ids[0][r])]["page"],
             "score": float(scores[0][r]), "text": chunks[int(ids[0][r])]["text"]} for r in range(10)]
```

Pipeline 2 Re-Ranking: (a) reuse same Top 10; (b) score 10 (query, chunk) pairs with Cross-Encoder cross-encoder/ms-marco-MiniLM-L-6-v2; (c) sort descending, take new Top 3; (d) same prompt and same LLM for Answer 2, only chunks differ.

```python
from sentence_transformers import CrossEncoder
reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")
def rerank_top10(query, hits):
    pairs = [[query, h["text"]] for h in hits]
    scores = reranker.predict(pairs)
    for i, h in enumerate(hits): h["cross_score"] = float(scores[i])
    return sorted(hits, key=lambda x: x["cross_score"], reverse=True)

from kaggle_secrets import UserSecretsClient
import google.generativeai as genai
genai.configure(api_key=UserSecretsClient().get_secret("newkey3"))
llm = genai.GenerativeModel("models/gemini-3.8-flash")

def make_prompt(query, top3):
    ctx = "".join([f"\nChunk {i+1}:\n{top3[i]['text']}\n" for i in range(3)])
    return ("You are a helper for NITI AI strategy document.\nAnswer only from given context.\n"
            f"If answer is not in context, say not found.\n\nContext:\n{ctx}\nQuestion: {query}\nAnswer:")
def get_answer1(query):
    hits = search_top10(query); top3 = hits[:3]
    return top3, llm.generate_content(make_prompt(query, top3)).text
def get_answer2(query):
    hits = search_top10(query); ranked = rerank_top10(query, hits); top3 = ranked[:3]
    return hits, ranked, top3, llm.generate_content(make_prompt(query, top3)).text
```

Top 10 cosine scores observed are close (0.55 to 0.58), so Bi-Encoder ranking is weak and re-ranking matters.

4. Analysis and Report
4.1 Architecture comparison. Bi-Encoder encodes query and chunk independently into vectors, then cosine similarity. Vectors precomputed once, search fast, but no query-chunk interaction, so it fails on synonyms (COREs) and negation (not/without). Cross-Encoder encodes (query, chunk) jointly with self-attention across tokens and outputs relevance directly. No precompute, must run transformer per pair, slow but context-aware. Hence retrieve-then-rerank: Bi-Encoder filters to Top 10 fast, Cross-Encoder reads only 10 carefully.
4.2 Qualitative and rank shift. Table above: 4 to 1, 8 to 2, 8 to 1, 5 to 3, 4 to 2, 7 to 3. Baseline hallucinations were limited by strict prompt (says not found instead of inventing); observed faults were omission (Q1, Q2 missed INR and workforce clauses because gold chunks at ranks 4-8) and noisy merging with duplicates (Q3, 8 points vs correct 4). Re-ranking restored relevance in all three scoring cases.
4.3 Latency profiling (Kaggle T4 x2, mean of 5 runs, 362 chunks). Baseline search Top 10: 0.0081 s. Cross-Encoder re-rank of 10 pairs: 0.0382 s extra (about 5x baseline). Retrieval total Pipeline 2 without LLM: 0.0463 s. Pipeline 1 with LLM: 0.377 s. Pipeline 2 with LLM: 0.467 s. Extra end-to-end cost about 0.09 s for clearly better answers. LLM dominates both pipelines; retrieval overhead is small at this scale.
4.4 Scaling. Cross-Encoder cannot be run on the full collection from the start because each query-chunk pair needs a full transformer forward pass with joint attention and nothing can be precomputed or indexed. 10 pairs cost 38 ms here; 362 chunks would cost about 1.4 s per query, and lakhs of chunks would take hours per query. Bi-Encoder vectors are precomputed and FAISS search stays fast. So Top 10 prefilter plus Cross-Encoder on 10 only gives speed plus accuracy (8 ms to 46 ms retrieval for Not found to Found).
